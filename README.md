One word for your Wi-Fi, entered in make.fun's "One Word for Your Wi-Fi" bounty ($2, winner takes all). The word is **Gaslighting** — full bars on the icon, "Connected" on the status page, and a browser tab that spins forever. The network swears nothing is wrong, so the fault must be yours.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the single entry word to `entry.txt` in the output directory (`/output` by default, or `$MAKEFUN_OUTPUT_DIR` when set), with no trailing newline.
